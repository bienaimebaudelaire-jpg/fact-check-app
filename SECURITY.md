# Politique de sécurité

## Versions supportées

Ce projet est en V1 scaffold et n'a pas encore de versions publiées
indépendamment. Seule la branche `main` est maintenue et reçoit des
correctifs de sécurité.

## Signaler une vulnérabilité

Merci de **ne pas** ouvrir d'issue publique pour une vulnérabilité de
sécurité potentielle. À la place :

1. Utilisez l'onglet **Security** du dépôt GitHub (« Report a vulnerability »)
   si disponible, ou
2. Contactez le mainteneur via un message privé GitHub.

Merci d'inclure :

- une description du problème et de son impact potentiel ;
- les étapes pour le reproduire ;
- la version/commit concerné(e).

Nous accusons réception dans un délai raisonnable et vous tiendrons informé(e)
de la résolution.

## Dépendances

Les dépendances sont surveillées via Dependabot (`.github/dependabot.yml`) et
un scan CodeQL hebdomadaire (`.github/workflows/codeql.yml`). Les mises à
jour de sécurité proposées automatiquement doivent être revues rapidement.
